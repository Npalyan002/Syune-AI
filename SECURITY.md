# Security policy

Report vulnerabilities privately to the repository owner. Do not put credentials,
exploit payloads, or private data in public issues. Supported stable release: `1.0.0`.

SYUNE enforces principal/purpose/scope authorization, redacts recognized secret fields
from audit, validates structured provider output, and constrains Study paths. Operators
remain responsible for filesystem permissions, encryption, backups, credentials, egress
controls, and audit integrity monitoring.
