# Contract boundary

Machine-readable public schemas live in versioned child directories. Existing schemas are compatibility contracts and cannot be changed silently.

The stable Lean surface covers governed memory, provenance, recall/context requests and results, ModelGateway execution, and durable audit. Experimental compatibility objects confer no execution authority. See the [public API](../docs/PUBLIC_API_V1.md), [Lean v1 architecture](../docs/architecture/LEAN_V1_ARCHITECTURE.md), and [compatibility matrix](../docs/COMPATIBILITY_MATRIX.md).
