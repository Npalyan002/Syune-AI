# Contract boundary

Machine-readable schemas and examples belong in the child directories after their serialization is decided. Phase 01 adds no machine-readable schema that could silently change Phase 00 semantics.

Categories reserved: identifiers; sources; provenance; concepts; claims/evidence; memory traces; activation state; study jobs/status; recall requests/results; cognitive context; domain activation; factual events; future action proposals. Future proposals confer no execution authority. See [contracts](../docs/SYUNE_CONTRACTS_v001.md), [memory model](../docs/SYUNE_MEMORY_MODEL_v001.md), and [event model](../docs/SYUNE_EVENT_MODEL_v001.md).
