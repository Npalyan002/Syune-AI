# ADR-0001 — Independent Repository

**Status:** Accepted  
**Baseline:** v001 / Baseline 0.1

## Decision

SYUNE is an independent, detachable repository and product with MCP as its first integration surface; the host application owns production execution.

## Rationale

Embedding it in the agent system would couple cognition to one framework.

## Consequences and boundaries

No ART-DEP-AI change or integration in Phase 00.

See [Constitution](../SYUNE_CONSTITUTION_v001.md) and [Blueprint](../SYUNE_BLUEPRINT_v001.md).
