# ADR-0002 — Shared Distributed Memory

**Status:** Accepted  
**Baseline:** v001 / Baseline 0.1

## Decision

One shared distributed associative memory holds knowledge; sources and derivatives remain distinct and traceable.

## Rationale

Separate domain stores fracture facts and cross-context reasoning.

## Consequences and boundaries

Physical database and distribution topology are deferred.

See [Constitution](../SYUNE_CONSTITUTION_v001.md) and [Blueprint](../SYUNE_BLUEPRINT_v001.md).
