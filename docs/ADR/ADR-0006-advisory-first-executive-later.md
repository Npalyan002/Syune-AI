# ADR-0006 — Advisory First Executive Later

**Status:** Accepted  
**Baseline:** v001 / Baseline 0.1

## Decision

Freeze L1 ADVISORY now; future Executive proposals pass Governance, Control Core, and Capability Registry.

## Rationale

Cognition and execution need separate capability-scoped authority.

## Consequences and boundaries

No agent dispatch or autonomy activation now.

See [Constitution](../SYUNE_CONSTITUTION_v001.md) and [Blueprint](../SYUNE_BLUEPRINT_v001.md).
