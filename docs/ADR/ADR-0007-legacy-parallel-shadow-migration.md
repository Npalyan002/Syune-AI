# ADR-0007 — Legacy Parallel Shadow Migration

**Status:** Accepted  
**Baseline:** v001 / Baseline 0.1

## Decision

Keep legacy ART-DEP-AI RAG/memory/learning through Parallel, Shadow, Hybrid, Consolidation, and Retirement gates.

## Rationale

Quality, latency, cost, provenance, rollback, and owner approval are needed before retirement.

## Consequences and boundaries

No legacy modification or deletion in Phase 00.

See [Constitution](../SYUNE_CONSTITUTION_v001.md) and [Blueprint](../SYUNE_BLUEPRINT_v001.md).
