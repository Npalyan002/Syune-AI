# SYUNE — Constitution

Version: v001 / Baseline 0.1. Status: Phase 00 architecture freeze.
Authority: [Blueprint](SYUNE_BLUEPRINT_v001.md), [Constitution](SYUNE_CONSTITUTION_v001.md), and root Phase 00 specification.
Current mode: L1 ADVISORY.

## Binding invariants

1. SYUNE is independent and detachable; MCP is its first integration. The host application retains production execution.
2. One shared distributed associative memory serves all contexts. Creative, finance, systems, and strategy are activation/reasoning profiles, never exclusive fact owners or separate databases.
3. Sources and derived memory are distinct. Every durable claim/trace retains provenance, evidence, version, and representable confidence/uncertainty. Disagreement remains visible.
4. Study is idempotent, incremental, resumable, auditable, and checkpointed. Important transitions are factual events.
5. RAG is one retrieval mechanism. LLM/VLM providers are replaceable processors behind adapters; SYUNE is provider and agent-framework agnostic.
6. Cognition and execution are separate. Current mode is L1 ADVISORY. SYUNE cannot dispatch agents, publish, mutate production state, or bypass approval. Future Executive Layer routes through Governance, Control Core, and Capability Registry with capability-scoped authority.
7. Legacy ART-DEP-AI RAG/memory/learning remains through Parallel, Shadow, Hybrid, Consolidation, and Retirement gates.
8. STEP 01–30 are functional cognitive requirements, not folders, services, or agents.
9. Raw source material remains traceable after abstraction; same information may participate in many contexts.

## Change control

Violating an invariant requires a new ADR and explicit baseline version change. Contradictions block progress. Git Markdown is the living source; PDF is a snapshot and DOCX a business copy.
