# SYUNE — Memory Model

Version: v001 / Baseline 0.1. Status: Phase 00 architecture freeze.
Authority: [Blueprint](SYUNE_BLUEPRINT_v001.md), [Constitution](SYUNE_CONSTITUTION_v001.md), and root Phase 00 specification.
Current mode: L1 ADVISORY.

## Shared ontology

Source is original material or observation. Concept is a semantic representation. Episode is a contextual/time-situated experience. Procedure is an ordered or conditional method. Claim is a proposition, not automatic truth. Evidence supports, contradicts, or qualifies a claim. Association is a typed/weighted relation. MemoryTrace is a durable derived trace. Provenance records source and transformation lineage. ActivationState is transient retrieval activation. Confidence represents uncertainty/evidence without erasing disagreement.

One shared distributed associative substrate holds all durable memory. A fact may connect simultaneously to creative, finance, systems, strategy, temporal, and causal contexts. Domain classification is metadata, not exclusive storage.

## Provenance

Required relationship semantics: derived_from, supported_by, contradicted_by, extracted_from, abstracted_from, consolidated_from, supersedes, invalidated_by. Both SOURCE → derived memories/claims/concepts and MEMORY/CLAIM → sources/evidence/transformations must be answerable. Retraction must reveal affected derivatives for recalculation; no silent orphans. Source truth and derived versions remain separate. Durable claims/traces require provenance, evidence, version, and confidence/uncertainty. See [Contracts](SYUNE_CONTRACTS_v001.md).
