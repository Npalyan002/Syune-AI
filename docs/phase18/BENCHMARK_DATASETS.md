# Benchmark datasets

The canonical dataset is `syune-competitive-baseline@1.0.0`, generated by generator `1.0.0` with default seed `1801`. Metadata includes dataset ID, dataset version, seed, generator version, fixed creation timestamp, case count, and SHA-256 content hash. Fixtures are synthetic and contain no credentials, personal data, production memory, or proprietary content.

The fifteen families map to Phase 17 gaps in `benchmarks/families.v1.json`: recall (G04/G20), temporal (G02), contradiction (G03/G31), provenance (G13), associative and multi-hop (G04/G31), update (G02/G12), abstention (G20), permission (G01), cross-agent (G10), learning (G09/G28), compression (G11), task success (G14/G20), context efficiency (G04/G20), and performance (G05/G17/G21).

Adversarial tags cover duplicates, near duplicates, stale and future facts, contradictions, false observations, unverified feedback, high-similarity distractors, similar entities, ambiguous names, permission conflicts, cross-agent contamination, distractor chains, missing evidence, and orphan provenance.

`--interactions` accepts 10, 100, 1,000, and 10,000. `--scale` accepts 10K, 100K, 1M, 10M, and 100M. These values identify planned workload points; smoke validation does not claim to materialize or measure the unexecuted heavy points. Heavy and stress execution needs an explicit resource plan before evidence may be reported.
