# Cognitive access model

`Principal` distinguishes user, agent, organization, project, department, and service identities. User and agent identities are independent. `AccessContext` adds purpose and task identity.

Usability is `truth eligible AND temporally eligible AND authorized`. Retrieval evaluates authorization before scoring and working-context assembly. Cognitive, Council, Planner, and Executive paths consume the already-authorized cognitive context; internal services receive no global bypass.

Maintenance or audit access must use an explicit service principal and a policy grant.
