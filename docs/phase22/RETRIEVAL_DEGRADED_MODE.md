# Retrieval degraded mode

Embedding or ANN unavailability increments a counter, marks the index `DEGRADED`, and returns no semantic seeds. Retrieval continues through exact, lexical, entity, temporal, and associative paths. Authorization, temporal eligibility, truth selection, and context construction still execute.

Dimension/space mismatch is an explicit rebuild condition, not a transient fallback. Canonical-memory and materialization failures retain typed errors.
