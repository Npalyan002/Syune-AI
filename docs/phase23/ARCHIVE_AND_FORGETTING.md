# Archive and forgetting

Archive is reversible by an explicit audited restore. Ordinary lexical, semantic, graph, cognitive, and council paths exclude archived records. Historical callers must explicitly request archive access and still pass authorization.

Forgetting is a cognitive tombstone, not deletion. It survives restart and rebuild and cannot use ordinary restore. Purge is explicit administrative physical deletion; it removes content and incident graph edges while retaining a non-content lifecycle/audit tombstone.
