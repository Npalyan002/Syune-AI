# Evidence and attribution

Evidence kinds distinguish task results, external evaluations, human feedback, deterministic tests, measured metrics, and system observations. Quality is the interpretable mean of source reliability, directness, independence, verification, and scope match.

Attribution is explicitly `DIRECT`, `SUPPORTED`, `POSSIBLE`, `UNKNOWN`, or `CONFOUNDED`. Default policy accepts only direct/supported attribution. Association with success is not represented as causation. Duplicate lineage and model self-evaluation share an independence key and cannot inflate independent support.
