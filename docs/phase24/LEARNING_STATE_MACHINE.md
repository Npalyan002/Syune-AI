# Learning state machine

Operational states are `OBSERVED`, `CANDIDATE`, `SUPPORTED`, `VERIFIED`, `PROMOTED`, `DISPUTED`, `DEMOTED`, and `REVOKED`.

One acceptable success creates only a candidate. Repeated compatible evidence creates support; policy thresholds create verification; verification materializes a retrievable procedure. Excess negative evidence disputes a hypothesis. Later independent failures demote and then revoke promoted knowledge. Historical experiences remain immutable.
