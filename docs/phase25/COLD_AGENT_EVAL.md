# Cold-agent evaluation

The controlled benchmark uses the same deterministic task policy in every arm. A cold isolated agent succeeds on 50% of cases. A cold agent with authorized organizational retrieval succeeds on 90%, a +40 percentage-point delta, without raw evidence access or model retraining.

This is synthetic product evidence, not a production-model claim. The acceptance signal is nevertheless exercised end to end: independently sourced experiences produce a scoped procedure, a new authorized agent retrieves it, and that agent cannot inspect source raw memory.
