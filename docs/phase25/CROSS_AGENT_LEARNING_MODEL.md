# Cross-agent learning model

The pipeline is: private experience admission → eligibility filter → exact context compatibility → provenance correlation clustering → quality-weighted verification → abstraction safety check → explicit scope grant → versioned procedure materialization.

The matching key retains task class, exact conditions, environment, generalized strategy, purpose, and target scope. Incompatible environments or applicability conditions therefore coexist rather than being forced into a global winner. Failures remain first-class contradicting evidence. Counts alone never establish truth: one correlation cluster contributes at most its best quality score.

Local experience is never organizational knowledge by implication. `eligible=False` is the default, and promotion is a separate call with a grant.
