# Cross-agent security

The experience pool has no unscoped raw listing API. Raw inspection reconstructs the source agent/project/organization/purpose envelope and invokes Phase 20 authorization. Use of a promoted procedure is a separate authorization decision against the target envelope.

For confidential or restricted sources, promotion requires an explicit sensitive-term manifest and a generalized strategy containing none of those terms. If deterministic safety cannot be established, promotion is blocked. Purpose, project, department, organization, and agent boundaries remain enforced during retrieval.

Threat tests cover private-data promotion, wrong purpose, cross-project behavior, cross-organization denial, correlated duplication, noisy evidence, and raw-evidence denial.
