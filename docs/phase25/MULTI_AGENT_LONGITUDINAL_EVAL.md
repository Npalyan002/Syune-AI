# Multi-agent longitudinal evaluation

Controlled checkpoints were executed at 10, 100, 1,000, and 10,000 synthetic experiences. Results stabilize from 100 onward at 90% task success, six reusable procedures in the multi-family model, and zero controlled contamination. The 10-experience checkpoint is 60% with no promoted procedures.

Agent-scale scenarios record 1, 10, 100, and 1,000 synthetic agents. These runs validate deterministic accounting and bounded promotion behavior, not production deployment at those agent counts. Evidence volume is capped per hypothesis and correlated identities do not add weight.
