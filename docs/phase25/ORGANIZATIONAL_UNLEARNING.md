# Organizational unlearning

New authorized failures are re-evaluated by independence cluster and quality. Negative weight above 1.2 demotes; above 2.0 revokes. The currently materialized procedure is archived through Phase 23 lifecycle handling, while evidence, audit events, prior immutable procedures, and revision metadata remain available for authorized audit.

Staleness is bounded by source `valid_until`, last-supported time, truth eligibility, and lifecycle state. Revoked or archived procedures are excluded by ordinary retrieval. A later revision receives a new deterministic procedure ID; an unchanged concurrent request is idempotent.
