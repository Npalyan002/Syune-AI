# Phase 25 benchmark delta

The immutable pre-state preserves the Phase 24 local-learning baseline. The post-state adds four separate arms, cold-agent and specialization outcomes, contamination dimensions, evidence independence, agent scale, longitudinal volume, promotion/maintenance latency, and ordinary decision latency.

Controlled deltas: cold-agent success +40 points versus isolation and +40 points versus local-only learning; cross-agent task success +20 points versus local verified; repeated errors -20 points versus local verified. Precision and recall are 100% on the deterministic fixture with zero false organizational promotions. Latency values are machine-specific and remain in the generated JSON.
