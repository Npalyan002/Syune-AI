# Memory versus learning

Could most Phase 24/25 gain be reproduced by retrieving prior successful examples? In this benchmark, **yes for local learning**: strong memory/RAG and local verified learning both score 75%. Local learning adds validation, reversibility, bounded procedure representation, and resistance to poisoned examples, but no incremental task-success result here.

Organizational learning scores 87.5%, 12.5 points above both. That delta comes from pooling independently verified experience across specialists and delivering it to a cold agent, not from a stronger task engine. More exposure is part of the product mechanism, so future evaluation must compare against an equally broad, access-controlled organizational RAG baseline—not a weaker local RAG baseline.
