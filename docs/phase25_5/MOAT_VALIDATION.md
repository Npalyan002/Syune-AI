# Moat validation

No component is declared a moat. The strongest candidate is governed organizational experience.

It improves controlled outcomes, can compound as specialists contribute, persists independently of model weights, accumulates organization-specific evidence, and remains auditable and reversible. It is harder to reproduce with a larger per-agent context because raw sharing creates contamination and privacy costs.

The case remains incomplete: an organization-wide, access-controlled RAG baseline may reproduce much of the gain; no real model was tested; cross-model survival is conceptual only; and the current benchmark ontology is small. Classification: **POTENTIALLY_DIFFERENTIATED / RESEARCH_REQUIRED**, not moat proven.

Competitive map: memory, RAG, provenance, vector search, APIs, and access control are COMMON or COMPETITIVE. Verified reversible learning and governed cross-agent evidence are POTENTIALLY_DIFFERENTIATED. Current competitor implementation detail is stale/insufficient, so exclusivity is UNKNOWN and requires refreshed research.
