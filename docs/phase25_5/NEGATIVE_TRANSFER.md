# Negative transfer

Six Linux-shifted tasks were tested against Windows-only learned applicability. SYUNE abstained from applying those procedures, yielding a 0% negative-transfer rate in the covered fixture. This result depends on exact applicability metadata and does not establish robustness to ambiguous or missing conditions.

Negative transfer is defined as a task harmed because retrieved learned knowledge was used. Future real-model evaluation must distinguish retrieval, actual use, and causal harm rather than assuming retrieved context influenced the answer.
