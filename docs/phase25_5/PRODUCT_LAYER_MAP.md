# Product layer map

| Layer | Capabilities |
| --- | --- |
| FOUNDATION | persistent memory, provenance, temporal truth, authorization, lifecycle, indexing, SDK/MCP/API |
| COMPETITIVE PARITY | hybrid retrieval, durable ingestion, bounded context assembly, audit surfaces |
| DIFFERENTIATOR CANDIDATE | controlled organizational learning, evidence independence, reversible governed knowledge, cold-agent reuse without raw sharing |
| RESEARCH / OPTIONAL | Council, profiles, L2 planner, L3 supervised executive, cognitive compression, model portability |
| TECHNICAL DEBT | real embeddings/Qdrant validation, archive search, maintenance scaling, sensitive-data classification trust, process-local SQLite concurrency, association scans |

Foundation quality is necessary but is not itself evidence of a moat. Verified local learning remains useful for governance and reversibility, but this benchmark does not distinguish its task quality from strong retrieval.
