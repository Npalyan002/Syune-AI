# Production model-call inventory

The complete `src/syune` audit found no direct generative provider execution outside approved
`model_gateway` adapters. Verified learning, organizational learning, cognition, council, planner,
and supervised execution are deterministic today. Therefore Phase 30 does not invent model calls
inside them.

Production paths: two P0 gateway/transaction boundaries, one P1 multimodal provider family, and two
P2 retrieval integrations. Benchmark runners and test fakes are separately classified. There are no
unknown, deprecated, or dead model paths. The canonical machine inventory is
`MODEL_CALL_INVENTORY.json`.
