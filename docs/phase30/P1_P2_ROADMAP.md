# P1/P2 roadmap

1. P1 multimodal perception: evaluate gateway alignment only when provider output can persistently
   affect cognition; retain modality limits and provider-specific media handling.
2. P2 embeddings: share budget, telemetry and secret-hygiene primitives without routing vectors
   through the text-generation gateway.
3. P2 Qdrant: retain its vector-store health and schema contract; it is not model generation.

Priority is based on side-effect severity and structured-output risk, not checklist completeness.
