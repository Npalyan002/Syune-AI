|---|---|---|
| Memory | GOVERNANCE_VALUE | Durable, scoped evidence and complete provenance; no isolated task lift established. |

| Organizational learning | NO_MEASURED_VALUE | No significant quality/repeated-error advantage; adaptation after correction was worse. |
| ModelGateway | GOVERNANCE_VALUE | Complete metering and failure evidence; live terminal rate exposed an operational weakness. |
| Cognitive transactions | GOVERNANCE_VALUE | Separate durable commits with no duplicate side effects; added measurable latency. |
| Audit | GOVERNANCE_VALUE | Audit and provenance completeness were both 100%. |

Provider economics favored SYUNE over query-time synthesis, but not enough to overcome the
failed truth gate, unresolved quality uncertainty, poor long-term adaptation and 3× component
complexity. This evidence does not justify a full or lean SYUNE product.
