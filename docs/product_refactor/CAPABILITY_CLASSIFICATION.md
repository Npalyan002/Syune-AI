# Capability classification

All 20 production capabilities are classified exactly once in [CAPABILITY_CLASSIFICATION.json](CAPABILITY_CLASSIFICATION.json). The allowed values are `V1_CORE`, `V1_OPTIONAL`, `EXPERIMENTAL`, `RESEARCH`, `DEPRECATE`, and `REMOVE`; there are no unknown entries. Narrative rationale is in [CAPABILITY_INVENTORY.md](CAPABILITY_INVENTORY.md).
