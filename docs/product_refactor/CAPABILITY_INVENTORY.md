# Capability inventory

The authoritative machine-readable inventory is [capability_inventory.json](capability_inventory.json). It contains 20 production capabilities and no `UNKNOWN` classifications. The only default V1 core is memory/provenance, authorization/audit, temporal metadata, lexical retrieval, lifecycle, context, Study ingestion, model gateway, SDK, and lifecycle CLI.

Optional features are MCP, semantic retrieval, associative expansion, and advanced consolidation. Learning and cognitive transactions are experimental. Profiles, council, and executive planning are research. The old public cognitive methods are deprecated compatibility shims.
