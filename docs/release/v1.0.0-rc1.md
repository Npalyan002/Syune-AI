# SYUNE v1.0.0-rc1 release notes

SYUNE is now a focused governed memory, context and model-execution runtime for AI
systems. RC1 provides durable scoped memory, hybrid retrieval, bounded provenance-rich
context, temporal/version and lifecycle governance, correlated audit, explicit revision,
reliable structured model execution, Python SDK and Lean MCP.

This is a release candidate, not final v1.0.0. Research cognition and learning remain
available only as disabled experimental/deprecated compatibility code. Deployment is
single-node SQLite and the default vector backend is local-linear. Distributed storage
and a production ANN backend are not included. No new Anthropic/Gemini live run was
performed for RC1.
