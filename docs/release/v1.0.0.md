# SYUNE v1.0.0

SYUNE is a governed memory, context and model-execution runtime for AI systems.

The stable v1 product provides persistent governed memory, hybrid retrieval, bounded
context assembly, principal/purpose authorization, scope isolation, provenance,
temporal/version semantics, revision history, lifecycle controls, durable audit, a
provider-neutral ModelGateway with structured-output reliability and bounded
budget/retry/repair/fallback behavior, plus stable SDK, MCP and API surfaces.

Learning, organizational learning, cognition, Council, Planner and Executive are not
part of the stable v1 product contract. Compatibility research code remains disabled by
default and is available only through explicit experimental opt-in.

Known limitations remain unchanged from RC1: deployment is single-node SQLite with no
distributed storage; high-contention multi-process writes are unsupported; the default
vector backend is local-linear rather than production ANN; Anthropic and Gemini were not
live-validated for this release; Linux was not RC-validated; audit is durable but not
cryptographically tamper-evident; and rapid Windows metadata replacement remains an
edge case under investigation.
