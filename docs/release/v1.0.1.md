# SYUNE v1.0.1

SYUNE v1.0.1 is a publication-alignment release. It aligns package, runtime and
documentation version surfaces; adds canonical project URLs to package metadata;
and introduces a GitHub OIDC workflow for PyPI Trusted Publishing.

There are no runtime semantic changes. Public API v1, the state schema and the Lean
v1 product contract remain unchanged from v1.0.0.

The publishing workflow runs only for a published stable GitHub release, builds the
exact triggering tag, validates that its tag and package versions agree, and uses the
protected `pypi` environment without a stored PyPI password or API token.
