# SYUNE v1.0.2

SYUNE v1.0.2 fixes first-run onboarding for the installed-package quickstart.

`python -m syune.quickstart` now selects a temporary demo-state location, initializes it
through SYUNE's canonical state initializer when necessary, and safely reuses existing
state. A relative `--state-root` is resolved by the CLI wrapper before entering the
absolute-path-only SDK boundary.

Expected state and configuration mistakes produce actionable command-line errors. There
are no runtime semantic changes outside the quickstart wrapper and no new product
capability.
