# SYUNE v1.0.3

SYUNE v1.0.3 aligns public documentation with the actual Lean v1 product.

- The MCP guide now documents the canonical eight-tool Lean server and both supported
  entry points.
- New integration guidance covers Codex, Claude Code, Claude Desktop, and generic stdio
  hosts while separating verified SYUNE behavior from host-specific configuration.
- Architecture documentation distinguishes Host Model Mode from optional ModelGateway
  Mode and explains when a separate provider credential is unnecessary.
- Provider claims now distinguish the stable provider-neutral gateway from internal
  concrete adapters and unimplemented transports.
- The stable SDK Study path and its TXT, Markdown, and text-PDF formats are documented,
  along with unsupported folder, repository, OCR, web, and structured-file ingestion.
- Multimodal perception is explicitly experimental and not productized.

There are no runtime semantic changes and Public API v1 remains unchanged.
