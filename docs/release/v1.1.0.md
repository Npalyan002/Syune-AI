# SYUNE v1.1.0

SYUNE v1.1 CONNECT adds stable onboarding and local readiness commands without changing
memory, retrieval, authorization, provenance, temporal, lifecycle, Study, ModelGateway,
storage, or audit semantics.

## Added

- Interactive and automation-friendly `syune setup` for Codex, Claude Code, Claude
  Desktop, generic stdio MCP clients, and the Python SDK.
- Persistent platform-conventional state, canonical idempotent initialization, absolute
  interpreter discovery, safe artifacts, and a real MCP handshake.
- `syune doctor` with actionable state, configuration, MCP, health, 8/8 tool-contract,
  and optional ModelGateway diagnostics.
- Host Model Mode guidance: the MCP host reasons; no separate LLM API key is required.

Setup does not edit third-party configuration. Quickstart remains a separate temporary
demonstration. Windows is the primary live-validated platform; portable path and command
handling are covered by tests.
