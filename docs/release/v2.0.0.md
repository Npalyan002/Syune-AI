# SYUNE v2.0.0

SYUNE v2.0.0 is the current open-source release. Its immutable source commit is
`23d76717feff156849acc5e6b66aac088cd92afb`; the historical v1 releases remain
unchanged.

## Highlights

- Native recall remains deterministic and governed, with a default result limit of 16
  and an explicit supported maximum of 100.
- The Remember API accepts optional timezone-aware source timestamps without confusing
  event time with ingestion, knowledge-recording, or fact-validity time.
- Transactional batch ingestion couples memory persistence with durable idempotency and
  payload-conflict detection.
- The optional AML Textual Memory adapter exposes authenticated Add and Search over the
  public SDK while preserving native ranking, authorization, temporal, and lifecycle
  behavior.
- The evaluation deployment is a single-application-process SQLite architecture behind
  an HTTPS reverse proxy, with bounded concurrency and evaluation-only storage.

## Compatibility

Existing callers that omit v2's optional fields retain their previous behavior. Public
API version 1, MCP contract version 1, and state schema 1 remain distinct from the
package's semantic version.

## Model disclosure

AML Add and Search do not invoke a generative LLM or reranker. Native semantic retrieval
does use deterministic feature hashing (`deterministic-token-v1`, 64 dimensions) to
produce vectors during indexing and conceptual query processing. Whether this mechanism
is governed as an embedding model by the AML open-source policy remains under organizer
review. No official AML score or leaderboard rank has been obtained.

## Installation

```console
git clone https://github.com/Npalyan002/Syune-AI.git
cd Syune-AI
git checkout v2.0.0
python -m pip install .
```

This source installation is documented without asserting that v2.0.0 is published on
PyPI. See the [installation guide](../installation.md) and
[v2 architecture](../architecture/SYUNE_V2_ARCHITECTURE.md) for details.

## Known limitations

SQLite supports the intended single-application-process deployment but is not a
distributed write store. The built-in vector index is local-linear rather than ANN.
The AML adapter supports Textual Memory only, and retrieval may legitimately return
fewer candidates than requested. See [known limitations](../known_limitations.md).
