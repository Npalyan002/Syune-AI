# Research context

SYUNE originated within a broader cognitive-system research program. Some advanced cognition, learning, Council, and Executive modules remain in the source tree as experimental compatibility dependencies; they are disabled by default and are not required for the lean v1 product path.

Historical research specifications, raw evaluations, provider transcripts, treatment datasets, and execution evidence are not part of this public repository. They are also outside the SYUNE v1 product contract. Public users should rely on the documented v1 APIs, SDK, MCP interface, ModelGateway behavior, configuration, and compatibility guarantees.
