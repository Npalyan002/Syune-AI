# syune namespace

The namespace contains the Lean v1 runtime plus disabled-by-default experimental compatibility modules. `evals` is an explicit diagnostic/test orchestration layer; runtime services never invoke it automatically. MCP remains an L1 advisory interface.

See the [Lean v1 architecture](../../docs/architecture/LEAN_V1_ARCHITECTURE.md) and [experimental module boundaries](../../docs/product_refactor/EXPERIMENTAL_MODULES.md).
